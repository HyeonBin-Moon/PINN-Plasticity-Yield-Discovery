# Physics-Informed Discovery of Yield Functions in Plasticity

This repository provides the official implementation of the paper:

**Hyeonbin Moon; Donghyuk Cho; Jecheon Yu; Jeong Whan Yoon; Seunghwa Ryu\***
*Physics-Informed Discovery of Yield Functions in Plasticity via Convex Neural Representations*

\* Corresponding author.

A preprint version of the paper is available at:
https://arxiv.org/abs/2606.19375

This code implements a physics-informed framework that discovers anisotropic **yield functions**
from full-field displacement and reaction force data, using a **convex neural representation**
embedded in differentiable elastoplastic stress integration.

---

## Overview

The yield function specifies the elastic domain, determines the onset of plastic deformation, and,
under associated flow, controls the direction of plastic straining. Identifying it is difficult
because yielding is never directly observed: full-field measurements such as digital image
correlation (DIC) provide displacements, but neither stress fields nor yield surface data.

This framework identifies the yield function as a mechanically constrained constitutive component
**inside** elastoplastic stress integration, rather than through direct stress-space supervision.
Training requires **no** stress observations, plastic strain measurements, direct yield surface
data, or a prescribed parametric yield function.

The framework consists of three components:

- **Convex neural representation.**
  An input convex neural network represents the yield function, enforcing **convexity** and
  **positive homogeneity of degree one** by construction through ReLU activations, removal of bias
  terms, and a smooth nonnegative reparameterization of the recurrent weights. The assumed
  tension–compression symmetry is imposed by symmetrizing the network output over sign reversals
  of the normal and shear stress components.

- **Differentiable stress integration.**
  An explicit forward Euler elastoplastic update propagates stress from displacement-derived strain
  increments. The discontinuous plasticity indicator is replaced by a sigmoid approximation whose
  sharpness follows an annealing schedule, keeping the stress response differentiable with respect
  to the network parameters while avoiding an implicit return-mapping solve during training.

- **Physics-informed force equilibrium loss.**
  Training minimizes the mismatch between internal force increments predicted from the stress
  update and external force increments constructed from measured reaction forces and zero-force
  equilibrium conditions. A single yield function is shared across all loading cases.

For deployment in conventional implicit finite element analysis, the discovered $C^0$ neural yield
function is post-processed into a $C^1$-continuous, positively homogeneous **polynomial surrogate**
composed of terms of degrees 2, 4, 6, and 8.

## Problem Setting

A rectangular specimen containing two elliptical voids is considered under plane stress. The voids
generate stress concentrations, strain gradients, and multiaxial deformation, so that a single
specimen geometry probes a broad region of the yield surface. Four loading cases are applied to the
same geometry to activate complementary regions:

| Case | Description |
|:--|:--|
| **UTx** | Uniaxial tension along the rolling direction (RD) |
| **UTy** | Uniaxial tension along the transverse direction (TD) |
| **BT** | Biaxial tension |
| **SS** | Simple shear |

The available measurements consist of time-resolved full-field displacement data and reaction
forces on the displacement-controlled boundaries.

---

## Data

Training data are generated by plane-stress finite element simulations in Abaqus, using a user
material subroutine with implicit backward Euler return mapping. The same mesh is used for the
forward simulation and the inverse analysis.

| Quantity | Setting |
|:--|:--|
| Mesh | 4,485 nodes; 8,576 linear triangular plane-stress elements |
| Displacement amplitude | $\delta = 0.5$ mm |
| Load increments | 500 per loading case |
| Sampling interval | Every 5 increments (100 snapshots per loading case) |
| Elastic constants | $E = 69$ GPa, $\nu = 0.3$ |
| Hardening law | $R(\bar\varepsilon^{\,p}) = 417.501\,(0.00457 + \bar\varepsilon^{\,p})^{0.22194}$ MPa |

Stress fields, plastic strain fields, and ground-truth yield surface data are **not** used as
training inputs; they are reserved for validation and interpretation.

## Benchmark Yield Functions

Three ground-truth yield functions are used, representing isotropic, quadratic anisotropic, and
non-quadratic anisotropic yielding:

| Benchmark | Type | Parameters |
|:--|:--|:--|
| **von Mises** | Isotropic | — |
| **Hill 1948** | Quadratic anisotropic | $F = 1.3251$, $G = 1.0730$, $H = 0.8799$, $N = 2.2014$ &nbsp;(AA6022-T4E32) |
| **Yld2000-2d** | Non-quadratic anisotropic | $\alpha_{1\text{–}8} = 0.9835,\ 1.1182,\ 0.7435,\ 0.8517,\ 0.8879,\ 0.6511,\ 0.9790,\ 1.0810$; $a = 6$ &nbsp;(ferritic stainless steel type 409) |

## Training Settings

| Quantity | Symbol | Setting |
|:--|:--:|:--|
| Training epochs | $N_{\text{epoch}}$ | 2,000 |
| Network architecture | — | 4 layers, 32 units per layer |
| Optimizer | — | Adam |
| Loss weights | $w_c$ | $1.0$ for all loading cases |
| Initial sharpness | $\beta_0$ | 4 |
| Sharpness update factor | $\eta_\zeta$ | 0.9, applied to $\zeta = 1/\beta$ |
| Sharpness update period | $N_\zeta$ | 200 epochs |
| Retained differentiation increments | $\mathcal{G}_c$ | $\{4,\ 8,\ 12,\ \dots,\ 100\}$ |

> **Note on $\mathcal{G}_c$.**
> Differentiating the flow direction $\mathbf{n}_\theta = \partial_\sigma \bar\sigma_\theta$ with
> respect to the network parameters introduces higher-order derivatives at every element,
> integration point, loading case, and time increment. To bound memory, this gradient path is
> retained only at the increments in $\mathcal{G}_c$. All other increments still advance the stress
> and internal-variable histories and contribute to the force equilibrium residual through the
> differentiable plasticity indicator. With sufficient memory, $\mathcal{G}_c$ may include all
> sampled increments.

## Additional Studies

- **Noise sensitivity.**
  Zero-mean, spatiotemporally correlated Gaussian noise is added to the displacement fields, with
  temporal correlation $\sigma_{\text{time}} = 5$ time steps and spatial correlation
  $\sigma_{\text{space}} = 5$ mm. Three levels are considered:
  $\sigma_{\text{noise}} \in \{0.1,\ 0.2,\ 0.3\}\ \mu\mathrm{m}$.

- **Epistemic uncertainty.**
  Estimated from a deep ensemble of 10 independently initialized discovery runs.

- **Polynomial surrogate.**
  Fitted to 100,000 stress samples drawn on the level set of the discovered neural yield function
  by minimizing the mean squared error against it.
